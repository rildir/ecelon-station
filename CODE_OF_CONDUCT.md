# Code of Conduct

Be kind and assume good intent. Critique code and ideas, not people. Harassment, personal attacks
and discriminatory language are not welcome in issues, pull requests or discussions.

Maintainers may edit, hide or remove contributions that break these rules and may block repeat
offenders. To report a problem, open a private security advisory on this repository or contact the
maintainer through the address on their GitHub profile.

This is a short adaptation of the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
